# Security Policy

## Reporting a vulnerability

Please report security problems privately through
[GitHub's private vulnerability reporting](https://github.com/koedame/webextension-nanokvm-capture/security/advisories/new).
Do not open a public issue for them.

We will reply within 7 days to confirm that we received your report, and keep you updated until it is fixed.

## Supported versions

Only the latest release receives security fixes.

## What counts as a vulnerability

- A web page, or another extension, gaining access to captured screenshots or recordings, or to the NanoKVM session, through this extension
- The extension reading or sending data beyond what its README describes
- A flaw in the build or release workflows that could let an attacker change what is published
- A vulnerable dependency that is reachable from the extension
