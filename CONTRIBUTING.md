# Contributing

**This repository does not accept outside contributions.** The source is public so that anyone can read it and use it under the license in this repository. Pull requests from anyone other than the maintainer are not reviewed or merged and may be closed without a reply.

Bug reports and questions can still be filed as [issues](https://github.com/koedame/webextension-nanokvm-capture/issues), without any promise of an answer. To report a vulnerability, follow [SECURITY.md](SECURITY.md) instead of opening an issue.
